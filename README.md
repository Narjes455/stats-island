# 🏝️ جزيرة الإحصاء — Stats Island

لعبة ثلاثية الأبعاد بأسلوب **روبلوكس (Obby)** لتعلّم **المتوسط الحسابي** و**الوسيط** و**المنوال**.

## فكرة اللعبة
- شخصية مكعّبة تتحرك وتقفز في عالم من المنصات العائمة.
- 4 مراحل: المتوسط الحسابي ← الوسيط ← المنوال ← التحدي النهائي (مختلط).
- في كل مرحلة 3 جسور زجاجية، وفي كل جسر 3 بلاطات عليها أرقام: **واحدة فقط صحيحة**، والخاطئة تنكسر!
- عند اختيار إجابة خاطئة تظهر طريقة الحل خطوة بخطوة، ثم تعود لبداية المرحلة وتتولّد أسئلة جديدة 🔄.
- الأسئلة تتولّد عشوائيًا في كل مرة، مع خيارات خاطئة مبنية على الأخطاء الشائعة (مثل أخذ الوسيط قبل الترتيب، أو اعتبار عدد مرات التكرار هو المنوال).
- نقاط، عملات ذهبية، مؤقت، ونجوم في النهاية.

## التحكم
| الإجراء | الكمبيوتر | الجوال |
|---|---|---|
| الحركة | `W A S D` أو الأسهم | عصا التحكم |
| القفز | مسافة | زر «قفز» |
| الكاميرا | السحب بالفأرة + العجلة | السحب على الشاشة |
| الدرس | `H` | زر 📘 |

## التقنيات
HTML + CSS + JavaScript و [Three.js](https://threejs.org) (r128) — ملف واحد بدون أي أدوات بناء.
